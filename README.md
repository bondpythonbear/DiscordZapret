> ### АНТИВИРУСНАЯ ПРОВЕРКА
> WinDivert способен вызвать срабатывание антивируса.  
> WinDivert перехватывает и фильтрует сетевой трафик и необходим для работы zapret.
> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные либо относящиеся к хакерским инструментам. В результате файл удаляется и помещается в карантин. Обычно такое обнаружение помечается как `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, Kaspersky предлагает параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, предпочтительно добавить исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте настройку "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (провайдер Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Этот вариант рекомендуется пользователям Windows 11
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно

2. Получите zip- или rar-архив со [страницы последнего релиза](https://github.com/bondpythonbear/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и активируйте пункт "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллических букв и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные инструменты:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — убрать стратегию и WinDivert из списка служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — включить или выключить обход для игр и других приложений, использующих UDP и TCP-порты выше 1023.  
  **После изменения этого параметра стратегию необходимо перезапустить.**  
  Текущее состояние показывается в скобках: включено или выключено.
  - **`IPSet Filter`** — изменить режим обработки сервисов из `ipset-all.txt`.  
  Опция полезна при поиске причины, если ресурс без zapret работает, а с ним — нет.  
  Текущий режим отображается в скобках:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить активный фейк на другой из каталога `bin`
  - **`Update IPSet List`** — загрузить свежий `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — выполнить диагностику распространённых причин неисправности zapret.  
  В конце процедуры можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Частые вопросы и неисправности

### После запуска `general*` не видно никаких изменений

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно заметить на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/bondpythonbear/zapret-discord-youtube/issues/522)

### Не удаётся подобрать ни одну стратегию
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открывшегося блокнота
  - Найдите созданную папку и откройте расположенный в ней файл `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец файла `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что hosts действительно был сохранён.

#### Результат не гарантируется. Если этот способ не помог, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/bondpythonbear/tg-ws-proxy) или одним из публичных прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Рабочие стратегии могут со временем перестать работать.**
> Вариант, который некоторое время успешно обходил блокировку, позже может быть обнаружен и перестать работать.
> Здесь собрано много разных стратегий. Если готовые варианты не подходят, создайте собственную, взяв одну из них за основу и изменив параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и убедитесь, что диагностика не сообщает об ошибках

- Проверьте, добавлен ли нужный ресурс в списки доменов или IP-адресов

- Испытайте другие стратегии, включая **`ALT`**, **`FAKE`** и остальные варианты

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/bondpythonbear/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить сборку?
- Сохраните ресурсы и данные, которые добавлялись вами вручную
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, а в конце ответьте Y
- Удалите каталог zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/bondpythonbear/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, отметьте его, нажмите «Применить», затем «ОК»
- Распакуйте архив в новый каталог в корне диска, исключив пробелы и специальные символы из пути
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не появился, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- После выбора работающего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на ресурсы, которые вы не собирались обходить.

### Античит обнаруживает WinDivert

- Следуйте инструкции: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё отображается среди служб

1. Узнайте имя службы в командной строке Windows. Открыть её можно через Win+R и команду `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше доступ уже работал.
- Также смотрите [#251](https://github.com/bondpythonbear/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её
- Через `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord
- Проверьте Discord и выясните, помогла ли очистка кэша
- Попробуйте открыть Discord через браузер: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не открывается и в браузере, снова протестируйте все стратегии: YouTube и Discord могут работать на разных вариантах
- Дополнительные сведения — в [#252](https://github.com/bondpythonbear/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/bondpythonbear/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить работу каждой из них невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не помогло, дополнительно попробуйте включить `ipset any`

Учитывайте, что режим `ipset any` способен нарушить открытие большого числа сайтов. Не оставляйте его включённым постоянно. Лучше определить IP-адреса, используемые конкретной игрой, и занести их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/bondpythonbear/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/bondpythonbear/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Расширить перечень адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, когда сеть присутствует в `ipset-all.txt`, но определённый домен из неё фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые необходимо исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` либо `service.bat`
